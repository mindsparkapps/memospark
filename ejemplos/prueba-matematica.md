## ¿Cuál es la solución de 2x + 6 = 14?

- [x] x = 4
- [ ] x = 10
- [ ] x = 3
- [ ] x = 7

Tema: Ecuaciones de primer grado
Referencia: Video «Ecuaciones de primer grado» — minuto 3:20 (https://www.youtube.com/watch?v=dQw4w9WgXcQ&t=200s)
Explicación: Se resta 6 a ambos lados (2x = 8) y se divide por 2.

## ¿Cómo se factoriza x² − 9?

- [x] (x − 3)(x + 3)
- [ ] (x − 9)(x + 1)
- [ ] (x − 3)²
- [ ] (x + 9)(x − 1)

Tema: Factorización
Referencia: Video «Productos notables y factorización» — minuto 12:30
Explicación: Es una diferencia de cuadrados: a² − b² = (a − b)(a + b).

## ¿Cuánto es 2³ · 2²?

- [x] 32
- [ ] 64
- [ ] 12
- [ ] 10

Tema: Potencias
Referencia: Apuntes de Álgebra, capítulo 2, p. 14
Explicación: Se suman los exponentes: 2⁵ = 32.

## ¿Cuál es el valor de x en 3x − 5 = x + 7?

- [x] x = 6
- [ ] x = 1
- [ ] x = 12
- [ ] x = 2

Tema: Ecuaciones de primer grado
Referencia: Video «Ecuaciones de primer grado» — minuto 8:45
Explicación: 3x − x = 7 + 5, luego 2x = 12 y x = 6.

## ¿Cuáles de estas expresiones son equivalentes a (x + 1)²? Marca todas las correctas.

- [x] x² + 2x + 1
- [x] (x + 1)(x + 1)
- [ ] x² + 1
- [ ] 2x + 2

Tema: Factorización
Referencia: Video «Productos notables y factorización» — minuto 5:10
Explicación: El cuadrado de un binomio es x² + 2x + 1, igual a multiplicar el binomio por sí mismo.
